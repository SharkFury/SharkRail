# Code of Conduct

SharkRail follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

We are committed to a welcoming, harassment-free community. Be respectful,
assume good intent while addressing impact, keep technical disagreement focused
on the work, and respect privacy.

Examples of unacceptable behavior include harassment, discrimination, threats,
sexualized attention, sustained disruption, publishing another person's private
information, and retaliation against a good-faith report.

## Scope

This policy applies in project spaces and when an individual is publicly
representing SharkRail. Project spaces include issues, pull requests,
discussions, reviews, release channels, and project events.

## Enforcement

Project maintainers may remove, edit, or reject contributions and may temporarily
or permanently restrict participation for behavior they reasonably consider
inappropriate. Enforcement should be proportionate, consistent, and respectful
of reporter privacy.

Report conduct incidents privately to the project maintainers. If no private
community contact is published, contact the repository owner through their
GitHub profile and request a private channel. Do not put sensitive incident
details in a public issue. Security vulnerabilities must follow
[SECURITY.md](SECURITY.md).

This concise project policy incorporates the Contributor Covenant principles;
the linked version provides the complete community guidelines and enforcement
ladder.
